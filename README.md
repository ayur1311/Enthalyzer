Enthalyzer - A DIY Instrumentation for Bioprocess Exhaust Gas Condensation and Analysis
Open-source 3D-printed condenser and ESP32-based sensor network for real-time thermodynamic monitoring of aerated bioprocesses.
Reliable measurement inside compact, humid, condensing environments is challenging, as conventional instrumentation is bulky and unsuitable for smaller scale setups. Additive manufacturing overcomes this by enabling complex internal geometries at low cost, iteratively refined core designs. With this work, we present a live monitored 3D-printed water-cooled condenser vessel for dehumidification of gas stream, which is easily printable, assembled from off-the-shelf fittings, and purposed for real-time performance monitoring in compact and DIY-friendly applications under €150.
The condenser core is a helical thin silicone coil (0.5 mm wall) through which chilled water flows while humid gas passes across it. A microcontroller reads all sensors every 10 s: two four-wire RTDs for water inlet and outlet temperatures, a flow sensor for water flow rate, and two combined temperature–humidity sensors for the gas stream, from which moist-gas enthalpy is derived. From these live readings the firmware computes the thermal duty (Q̇), the logarithmic-mean-enthalpy-difference (LMED), effectiveness (%), and the overall enthalpy-based transfer coefficient (U), all streamed to a custom dashboard for continuous monitoring. This demonstrates that a low cost sensor setup can track thermodynamic performance metrics that would otherwise require laboratory grade instrumentation, while producing time-resolved data valuable for validating and calibrating simulation models.
